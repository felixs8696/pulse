# Provider logos

Bundled for offline use in this personal local session tracker. Brand marks belong to their respective owners.

- Cursor: official 2D cube, light and dark variants from https://cursor.com/brand and https://ptht05hbb1ssoooe.public.blob.vercel-storage.com/assets/brand/cursor-brand-assets.zip (General Logos/Cube/SVG).
- Claude: authentic orange Claude mark from Anthropic's installed `anthropic.claude-code-2.1.304-darwin-arm64/resources/claude-logo.svg` extension asset.
- OpenAI: knot mark from https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/openai.svg (MIT icon collection). OpenAI's official brand page returned HTTP 403. Only foreground color differs between the two contrast variants.

SVG intrinsic dimensions are normalized for native rendering; path geometry is unchanged. Claude retains its supplied #D97757 color. Cursor uses the supplied warm white/charcoal colors; OpenAI uses warm white/charcoal for contrast. The shelf currently uses a fixed dark appearance; the artwork component also supports light appearance if the shelf later gains that option.

## Pulse mark

The blue comet mascot is generated artwork created for Pulse. Its three poses are bundled in `../Comet/comet-poses.png`. The thumbs-up pose is used for the app icon and logo. The app uses native macOS system fonts; no custom fonts are bundled.
